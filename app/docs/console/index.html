Team console

Seats and org billing live in the account app (web/account), not on this marketing site.

Locally: run cd web/account && npm run dev, then open http://127.0.0.1:3000/console/welcome.

In the desktop app, set MD_TEAMS_URL=http://127.0.0.1:3000/console/welcome (or rely on the new default).
